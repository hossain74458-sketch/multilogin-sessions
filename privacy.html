Privacy Policy for MultiLogin Sessions

Last updated: 22 November 2026

MultiLogin Sessions ("the extension") lets you use several logins on the same website at once, in separate sessions.

What the extension handles

To do this, the extension handles authentication information: the cookies your websites set while you are inside a session. It also stores the names and colours of the sessions you create, and which tab belongs to which session.

Where it is stored

All of this data is stored only on your own device, in the browser's extension storage. The extension has no server, does not send this data anywhere, does not sell or share it, and does not use analytics, advertising or tracking. The data is used only to provide the multi-login feature described above, and is not used for any other purpose, including advertising or credit decisions.

Export and import

If you use "Export Json", the extension saves a file to your computer that contains the login cookies of that session. This file is created only when you press the button and is never uploaded by the extension. Keep it private, because anyone with the file may be able to use those logins. "Import session file" reads a file you choose from your computer.

Permissions

The extension asks for access to all websites only so it can separate cookies and storage for the tabs that you have put inside a session. Its scripts load on web pages and its network listeners see requests so that it can tell whether a tab is inside a session, but for tabs that are not in a session they do nothing: they do not read, store or change anything, and the extension does not record your browsing history.

Deleting your data

You can delete one session's logins with "Clear logins", delete a session with "Delete", or remove all data by uninstalling the extension.

Links

The extension contains a link to a Telegram page for feedback and a link to an optional donation page. Nothing is sent to these unless you choose to open the link yourself.
